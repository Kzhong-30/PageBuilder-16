## 1. 产品概述

网页截图标注工具是一款面向产品经理、设计师和开发者的轻量级标注协作工具。支持通过 URL 加载网页或上传本地 HTML 文件，对截图进行多种标注操作，并可导出标注结果。
- 解决产品评审、设计走查、Bug 标注等场景下的截图标注需求
- 目标用户：产品经理、UI/UX 设计师、前端开发者、QA 测试人员

## 2. 核心功能

### 2.1 用户角色
无角色区分，单用户本地使用工具。

### 2.2 功能模块
1. **主页面**：网页加载区、截图预览区、标注画布、工具栏、标注列表、导出功能

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 主页面 | 网页加载 | 支持输入 URL 通过 iframe 加载网页，或上传本地 HTML 文件 |
| 主页面 | 截图预览 | 使用 html2canvas 对 iframe 内容截图，展示截图预览 |
| 主页面 | 标注工具栏 | 矩形框选、圆形框选、箭头指向、文字标注、马赛克模糊、自由画笔；支持颜色选择和线宽调节 |
| 主页面 | 标注画布 | Canvas 叠加层，实时渲染标注操作 |
| 主页面 | 撤销/重做 | 支持撤销和重做标注操作 |
| 主页面 | 标注列表 | 右侧面板显示所有标注，点击跳转定位，支持编辑文字和删除 |
| 主页面 | 导出功能 | 导出标注后图片为 PNG，导出标注数据为 JSON |
| 主页面 | 对比模式 | 左右分栏显示标注前后对比 |
| 主页面 | 历史持久化 | 使用 localStorage 保存标注历史 |

## 3. 核心流程

1. 用户输入 URL 或上传 HTML 文件 → 系统加载网页内容
2. 用户点击"截图"按钮 → html2canvas 截取网页 → 显示截图预览
3. 用户选择标注工具 → 在截图上绘制标注 → 标注数据实时记录
4. 用户可在标注列表中管理标注（编辑文字、删除、跳转定位）
5. 用户可撤销/重做操作
6. 用户可导出标注图片或标注数据
7. 用户可切换对比模式查看标注前后对比

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深灰 (#1a1a2e) + 亮橙 (#ff6b35) 强调色
- 辅助色：冷灰 (#16213e)、浅灰 (#e8e8e8)
- 按钮：圆角胶囊形，hover 时微浮动效果
- 字体：DM Sans（正文）、Space Mono（工具标签）
- 布局：顶部工具栏 + 中间画布区 + 右侧面板
- 图标风格：线性图标，2px 描边

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 主页面 | 网页加载区 | URL 输入框 + 加载按钮 / 文件上传按钮，居中布局 |
| 主页面 | 工具栏 | 水平排列图标按钮组，选中态高亮，颜色/线宽选择器 |
| 主页面 | 画布区 | 居中白色画布，阴影浮层，上方叠加 Canvas |
| 主页面 | 标注列表面板 | 右侧抽屉式面板，卡片列表，hover 高亮 |
| 主页面 | 导出区 | 工具栏右侧导出按钮组 |

### 4.3 响应式
- 桌面优先设计，最小宽度 1024px
- 标注列表面板可折叠
- 画布区自适应容器宽度

### 4.4 3D 场景指引
不适用
